# RevGuard 录制专用案件驾驶舱

面向 Agent Infra 复赛 Demo 的本地 WebUI。页面使用合成业务数据，但调查、审批、受限执行、独立验证、自动回滚和审计链路均由 RevGuard API 实际运行。

## 启动

在 `revguard/` 目录执行：

```bash
make demo-ui
```

然后打开 <http://127.0.0.1:9000/demo/>。

## 推荐录制顺序

1. 点击“重新准备”，停留 3 秒，交代“合成业务数据 · 真实运行链路”。
2. 点击“启动多 Agent 调查”，展示 8/8 强证据、政策时点匹配、确定性计算和 L2 审批边界。
3. 点击“批准并执行 14,400 KES”，展示两笔受限写入。
4. 强调 Verifier 与 Executor 为不同主体；Verifier 读取到 32,401 KES，发现 1 KES 偏差。
5. 展示两笔自动冲销和 `ROLLED_BACK / PASSED` 安全终态。
6. 依次切换“执行与审计”“权限边界”，展示 Trace、能力约束与安全探针。

建议使用 1440×900 或更高分辨率录制，浏览器缩放保持 100%。录制前关闭无关通知，并预跑一次确认 API 已启动。

## 安全边界

- 仅在 `REVGUARD_ENABLE_RECORDING_UI=true` 时开放演示重置接口。
- Dashboard 接口只返回令牌指纹，不返回审批令牌或回滚令牌原文。
- 页面中的 CRM、合同和财务数据均为合成数据，不代表真实企业交易。
