## 视觉与内容结论

- 布局：保留顶部案件摘要、8 阶段治理流水线、下方详细数据区和右侧安全栏，信息分组与视觉源一致。
- 层级：流水线仍是首要视觉焦点；证据、政策、计算、审批、执行、独立验证、回滚和回滚后验证的顺序清晰。
- 色彩：深海军蓝作为底色，青色表示已完成治理节点，橙色表示受控动作，红色表示验证失败，绿色表示安全恢复。
- 数据：证据表、政策时间线、计算账本、Agent 责任矩阵、Trace 与审计事件均来自 Dashboard 聚合接口；无执行结果硬编码。
- 字体与图标：Inter Variable 搭配系统中文字体；统一使用 Phosphor 图标，没有手绘 SVG、emoji 或占位图标。
- 状态：初始态不预填已校验、已执行或已回滚结果；调查态和审批后终态均由真实 API 响应驱动。

## 交互与响应式验证

- 已实机验证“重新准备 → 多 Agent 调查 → 人工审批 → 受限执行 → 独立验证 → 自动回滚”主路径。
- “决策依据”“执行与审计”“权限边界”三个页签均可切换，关键内容可见。
- 1024px 和 390px 视口没有页面级水平溢出；移动端流水线使用局部横向滚动，页签保持可操作。
- 使用语义化按钮、表格和导航，键盘焦点清晰；`prefers-reduced-motion` 下关闭旋转和顺滑滚动。
- 浏览器控制台无 error 或 warning。
