## 2. 修正了什么

- Higress 模板不再对对象二次 JSON 编码，避免 `input` 变字符串触发 HTTP 422。
- Adapter 识别 MCP `isError`，保留 HTTP 错误类型及安全摘要；已配置 MCP 不回退直连 REST。
- Worker 未返回持久化结果时，错误包含阶段、超时时长/原因及 request_id，不能只显示 FAILED。
- 网关直接按角色注册，不再使用默认向所有 Worker 授权的通用脚本。
- consumer PUT 是追加而非替换；兼容旧部署时，只撤销指定 RevGuard Server 的多余授权。
- 部署强制通过 9 次自身工具发现、72 次跨角色 401/403 拒绝；网络错误和 404 不算隔离成功。
- 后端示例 Worker key 更换为随机私密值；职能 Worker 仅持网关 consumer token。
- 人审身份验证 span 计入真实认证耗时；显式审批白名单在重新部署时保留。
- UI 保留负数调整，不再遗漏销售佣金 -7,000 或显示 `+-7,000`；冲销使用中文组件名。
- 正常 CLOSED/PASSED 分支显示“正常闭环”“无需回滚”，不再误写“等待回滚复核”。
- 安全侧栏从真实独立验证/回滚复核取金额，不用原始台账冒充已测得的恢复值。
- 页面入口及 API 响应禁止缓存，避免部署后继续读取旧版入口或案件状态。
- 安全回归、本地 stdio 排练与灰度模板标注存档/配置属性，不冒充当前现场执行。
- AgentTeams 通信配置不再自动显示“9 个房间验收通过”；配置检查与实跑证据分开。
