# 案件快照与 Worker 并发验收（2026-09-12）

RevGuard 0.5.6 已部署到 10.10.10.202 Docker。所有构建、测试、故障和浏览器检查均在 202 Docker 内执行。

| 复现的问题 | 修正和验证 |
| --- | --- |
| 旧案件快照、迟到的 Matrix 进度覆盖已推进的业务状态 | 案件写入比较录制批次和 `_case_revision`；Matrix 仅更新当前进度；独立数据库连接竞争时仅一次写入成功，HTTP 返回可刷新的 409 |
| Worker 初次验证之后、领取之前案件已改变，或两个 Worker 同时领取 | 在数据库事务内重新核对案件、任务、身份、输入，领取和开始审计一起提交；领取失败不调用 Skill |
| 完成审计失败留下成功任务，或旧尝试写回后一次执行 | 任务、StageResult 和完成审计一起提交；按领取的 attempt 拒绝过期回执 |
| 迟到的 Matrix Token / 事件信息覆盖已提交结果 | 元数据按允许字段原位合并；新任务只允许插入，重复 task_id 不替换结果 |
| 结果未知后 Matrix 仍重复提醒 Worker | `RESULT_UNKNOWN` 立即结束轮询；只提醒待执行或明确可重试失败的任务 |

`reproduced.log` 保存原版 6 项失败（SQLite/PG 各三项）。最终发布门禁包含 **267 项唯一测试**：主套件通过 208 项，59 项 PostgreSQL 测试另行全部通过，覆盖率显示 **91%**；确定性评测 105/105。Ruff、生成契约检查、pip-audit、Bandit 通过。前端源代码沿用已验收版本，本批次没有新增前端单元测试结论。

隔离浏览器执行真实 RevGuard API/MCP 链，覆盖审批写入失败、正常审批、已批准但执行交接中断后的人工恢复。两条成功路径均完成 16 个实际 MCP StageTask、两条执行记录，最终 CLOSED，队列 COMPLETED；手机宽度无外层溢出。身份服务为隔离 Matrix HTTP 契约夹具，不代表本轮重验生产 AgentTeams/模型服务。

生产只更新 API 镜像，原 8 个案件及其执行记录、9 条 ledger、261 行有效审计链前后一致。Grafana 的同源只读 iframe、12 个面板查询、全屏、手机宽度和 4 个 Prometheus 抓取目标均通过。Trivy 使用 `--ignore-unfixed`，实际发布镜像可修复 HIGH/CRITICAL 为 0，镜像 ID 与扫描一致。

这次验收覆盖案件快照与任务领取/完成，并不代表进程中断后的整个恢复流程已经原子化。运行中旧 Worker 的后续工具调用隔离、恢复续签与排队一致性、完整冷部署、其他 UI 状态及比赛材料仍需继续复核。外部 ERP Saga、企业真实收益、云 HA/PITR 均不在此证据范围内。
