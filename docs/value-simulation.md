# 企业价值模拟口径

RevGuard 驾驶舱的“价值模拟”页签用于把可复算的合成样本基线转换为企业可讨论的预算情景。
它不是客户案例、生产实测或现金节省承诺。

## 当前基线

输入来自 `data/value_baseline/synthetic_demo.csv` 的 8 个 Golden Case，全部标记为
`synthetic_demonstration`：

| 指标 | 人工基线 | RevGuard 辅助 | 派生结果 |
|---|---:|---:|---:|
| 单案处理中位时长 | 127.5 分钟 | 19.5 分钟 | 每案释放 108 分钟，时长下降 84.71% |
| 同等工时理论吞吐 | 1× | 6.54× | 只表示样本时长比值 |
| 错付样本率 | 75% | 0% | 只表示 8 个合成样本表现 |
| 追回成本指数 | 37,200 | 1,800 | 下降 95.16%；未指定企业结算币种 |
| 审计异常样本率 | 87.5% | 0% | 只表示合成测试是否触发异常 |

## 交互模拟公式

用户只输入两个企业侧假设：月均异常案件量 `V` 和综合人工成本 `C`（元/小时）。

```text
每案释放分钟 = 127.5 - 19.5 = 108
月度释放工时 = 108 × V ÷ 60
月度人工经费空间 = 月度释放工时 × C
年度人工经费空间 = 月度人工经费空间 × 12
FTE 月产能折算 = 月度释放工时 ÷ 160
```

默认情景 `V=500`、`C=100` 时，输出为 900 小时/月、约 5.6 个 FTE 月产能、
90,000 元/月和 1,080,000 元/年的人工产能折算。这里的“经费空间”表示可释放工时的
理论成本，不代表人员直接减少或财务报表中的已实现节省。

## 生产使用边界

企业落地时必须用已授权且可追溯的实测 CSV 替换合成基线，并至少记录样本周期、案件定义、
人工计时方法、综合用工成本构成、返工与升级口径。只有所有行均标记为
`measured_production` 且提供 `source_reference`，评估器才会把
`production_claim_allowed` 设为 `true`。

生成和验证命令：

```bash
make value-evaluate
python -m unittest tests.test_value_evaluation -v
```
