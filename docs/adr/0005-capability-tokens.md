# ADR-0005：能力令牌

- 状态：已采纳
- 日期：2026-08-12

## 背景

仅凭“审批已通过”的布尔值无法证明审批对象、金额、用途、有效期和是否已消费，重放也难以阻断。

## 决策

高风险写操作使用 `RGC1` HMAC-SHA256 能力令牌。载荷绑定签发者、用途、case/action/金额等业务声明、签发/过期时间和唯一 `jti`。验证采用常量时间签名比较，并检查用途、业务绑定、时效与一次性消费。日志、Trace、API 响应和证据包只保留脱敏值或不可授权的短指纹。

## 后果与验证

- 伪造、过期、跨 case、跨 action、跨用途和重放令牌均失败。
- 签名密钥必须由运行环境提供；Demo key 只能在显式不安全模式使用。
- 令牌是最小写能力，不是登录会话，也不替代 API Principal。
