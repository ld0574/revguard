# ADR-0001：确定性金额内核

- 状态：已采纳
- 日期：2026-08-12

## 背景

佣金复算、差异金额与舍入结果会直接决定是否写台账。把金额计算交给生成式模型会引入不可复现的输出，也无法为审计提供同输入同结果的保证。

## 决策

金额、门槛、适用条件和舍入由 `Decimal`、版本化规则 DSL 与确定性规则引擎执行。Agent 负责组织证据与解释，`CommissionCalculateSkill` 只接受结构化事实和规则。Normalize 与 Explain 在当前 Demo 中同样是确定性实现，不将模板逻辑包装成模型推理。

## 后果与验证

- 同一输入、政策版本和代码版本得到一致金额与 `calculation_hash`。
- 政策缺失、字段错误和契约错误显式失败，不以自然语言猜测补值。
- Golden、风险、政策与安全评测覆盖确定性结果；CI 不比较抖动耗时。
